# Slide Changer

**Slide Changer** is a sleek, remote presentation control application built with Electron and Node.js. It allows you to control your slideshows (PowerPoint, Google Slides, etc.) directly from your mobile device through a beautiful, web-based interface.

![Logo](_Internal/Project_Source/public/logo.png)

## 🚀 Features

- **Remote Control**: Navigate next, previous, and play/pause from any mobile device on the same network.
- **WebSocket Communication**: Instant response times without delays.
- **Glassmorphism Design**: A premium, modern UI with smooth animations and dark mode.
- **Auto-Discovery**: Displays your local IP and QR code for easy mobile connection.
- **Native Key Injection**: Uses a native C# helper for reliable cross-application compatibility.

## 🛠️ Technology Stack

- **Frontend**: Vanilla HTML5, CSS3 (Custom Design System), Socket.io Client.
- **Backend**: Node.js, Express, Socket.io.
- **Desktop Wrapper**: Electron.
- **Native Bridges**: C# (KeySender helper).

## 📦 How to Use

1. **Launch**: Open `Slide changer.exe`.
2. **Connect**: Scan the QR code shown in the app or enter the displayed URL on your mobile browser.
3. **Control**: Use the mobile interface to navigate your slides.
